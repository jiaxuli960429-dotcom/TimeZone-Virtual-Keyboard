========================================
  虚拟键盘 — 直播使用说明（简版）
========================================

【最重要】详细图文式步骤请看同文件夹里的：
        使用说明.md
（用记事本或 VS Code 打开即可。）

本文件是精简版，方便不打开 Markdown 时快速查阅。

----------------------------------------
一、启动
----------------------------------------
（免 Python：到 GitHub Releases 下载 TimeZoneKeyboard.exe，双击运行。）

1. 双击 TimeZoneKeyboard.exe（源码版：仓库根目录 start-keyboard.bat，需已装 Python）
2. 等待浏览器打开，地址必须是：
   http://localhost:8080
3. 不要双击 index.html 用“本地文件”打开，否则无法保存配置。

----------------------------------------
二、两个地址别搞混
----------------------------------------
【控制台】自己改键盘用：
  http://localhost:8080

【OBS 里填的】给观众看的、只有键盘的画面：
  在页面上方「OBS 浏览器源」卡片里，复制输入框中的整段地址。
  一定包含 /overlay?config= 这一段。
  不要把控制台首页填进 OBS。

----------------------------------------
三、全局按键捕获
----------------------------------------
控制台预览区附近会显示例如：
  全局按键捕获：已连接
若未连接，按键在游戏里可能不亮。请先保持 TimeZoneKeyboard.exe（或 bat）已运行。

----------------------------------------
四、保存方案
----------------------------------------
打开「配置」标签，使用「保存」「另存为」；
文件会出现在本文件夹 configs\ 下（.json）。
改完后若要用 OBS，建议用「保存并复制」更新链接。

----------------------------------------
五、常见问题（极简）
----------------------------------------
• OBS 不亮：检查是否用了 overlay 链接；刷新 OBS 浏览器源。
• 不能保存：检查是否用 http://localhost:8080 打开。
• 看报错：在文件夹打开终端，运行： python key_server.py
