========================================
    DOTA 键盘按键显示插件 - 使用说明
========================================

文档分工说明：
- README.md：项目介绍与快速启动（简版）
- USER_GUIDE.txt（本文件）：详细操作与排障（详版）
- docs/*.md：开发维护文档（给开发者）

📦 文件说明
-----------
- index.html          : 主程序文件
- keyboard.js         : 键盘逻辑代码
- key_server.py       : 全局按键捕获服务（解决浏览器失焦问题）
- configs/default.json: 首次打开时的默认键位布局（可改；勿删文件名）
- start-keyboard.bat  : 一键启动脚本
- USER_GUIDE.txt      : 本说明文件


🚀 快速开始
-----------
方法1: 双击运行 start-keyboard.bat
       - 会自动启动按键捕获服务和浏览器
       - OBS中添加浏览器源，URL填: http://localhost:8080

方法2: 手动启动（如果方法1有问题）
       1. 在终端执行: python key_server.py（保持运行）
       2. 浏览器打开: http://localhost:8080
       3. 在 OBS 中添加浏览器源


🎮 OBS设置
----------
1. 打开OBS，在来源中添加"浏览器"
2. URL填写: http://localhost:8080
3. 宽度建议: 1200, 高度建议: 400
4. 勾选"使用自定义帧率": 60 FPS
5. 勾选"当源变为活动状态时刷新浏览器"


⚙️ 自定义设置
-------------
按 F2 键显示/隐藏设置面板

1. 更换背景图:
   - 点击"背景图片"选择图片
   - 支持 PNG、JPG 格式
   - 建议尺寸: 1200x400

2. 调整透明度:
   - 按键透明度: 调整按键显示深浅
   - 背景透明度: 调整背景图深浅

3. 修改按键颜色:
   - 点击颜色选择器选择喜欢的颜色

4. 添加/删除按键:
   - 点击"添加按键"，然后按想添加的键
   - 在按键列表中点击"删除"移除按键

5. 调整按键位置:
   - 直接用鼠标拖拽按键到想要的位置

6. 编辑已有按键:
   - 画布上: 双击某个按键打开编辑窗口
   - 设置面板里的列表: 单击一行打开编辑，双击一行删除该键


💾 保存配置
-----------
- 用 start-keyboard.bat 启动后，务必用 http://localhost:8080 打开页面（不要用本地文件路径直接打开 html）
- 在设置里填写配置名称，点「保存到项目」→ 写入本文件夹 configs/ 下的 .json
- 点「刷新列表」，可在下拉框里「加载所选」或「删除所选」
- 仍会同步写入浏览器缓存；也可用「导出 JSON / 从文件加载」做备份或换电脑
- 启动时程序会自动尝试释放 8080 端口（排除本进程），一般无需再手动关旧服务。若你故意与其它软件共用 8080，可设置环境变量 OVERLAY_SKIP_HTTP_PORT_RECLAIM=1 后启动 key_server（不推荐）


🎯 DOTA默认按键

插件已预设DOTA常用按键:

🔧 常见问题
-----------
Q: 用 bat 启动后，按键服务好像没反应、也看不到报错?
A: bat 里用 pythonw 启动服务，故意不显示黑窗口，所以错误信息你看不到。
   排查时请打开「命令提示符」或 PowerShell，cd 到本文件夹后执行:
      python key_server.py
   这样会弹出窗口并打印日志，便于确认是否缺依赖、端口是否被占等。

Q: 页面或 OBS 里不显示按键?
A: 按顺序检查：
   1. 页面是否用 http://localhost:8080 打开（不要直接双击 html）
   2. 右下角是否显示「全局按键捕获：已连接」
   3. OBS 浏览器源 URL 是否填写 http://localhost:8080
   4. 刷新页面 / 刷新 OBS 浏览器源

Q: 如何换电脑使用?
A: 把整个文件夹复制过去就行，配置会跟着走

Q: 保存配置失败或看不到已保存配置?
A: 常见原因是没有通过本地服务打开页面。请确认：
   1. 已运行 start-keyboard.bat 或 python key_server.py
   2. 页面地址是 http://localhost:8080
   3. 点过「刷新列表」后再加载/删除


📞 技术支持
-----------
如有问题，请检查:
1. 是否使用最新版Chrome/Edge浏览器
2. key_server.py 是否正常运行（黑窗口不能关闭）
3. OBS浏览器源设置是否正确
4. 右下角是否显示「全局按键捕获：已连接」
