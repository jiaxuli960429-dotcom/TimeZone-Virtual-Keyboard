# 文档导航

本目录存放项目的前端行为约束与模块拆分说明，供开发和回归测试使用。

## 给开发者

- 本仓库已切换为 Server + Local Agent 架构，开发入口见根目录 `README.md`。

## 文档列表

- `frontend-baseline.md`
  - 前端行为基线：记录当前可观察行为与最小回归清单。
  - 用途：重构后快速核对“行为是否一致”。

- `frontend-modules.md`
  - 前端模块职责说明：记录各模块边界和关键约束。
  - 用途：新功能开发、问题定位与后续继续拆分。

- `online-migration-plan.md`
  - 在线化改造路线：Server + Local Agent 的拆分目标与里程碑。
  - 用途：将本地工具逐步迁移为在线平台。

- `mvp-roadmap.md`
  - 业务与功能路线图：个人配置库、创意工坊、B 站登录分阶段落地。
  - 用途：规划开发优先级与验收闭环。

- `config-json-format.md`
  - 配置 JSON 在数据库中的包装结构与前端兼容原则。
  - 用途：开发个人配置库和创意工坊时避免格式漂移。

## 推荐阅读顺序

1. 先看 `frontend-baseline.md`，明确不可破坏的行为。
2. 再看 `frontend-modules.md`，了解当前代码责任划分。

## 维护建议

- 修改交互行为时，先更新对应文档，再改代码，最后执行回归清单。
- 每次较大重构后，补充“行为约束”与“模块边界”变化。
